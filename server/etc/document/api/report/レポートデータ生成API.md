# レポートデータ生成API

## 目的

レポートデータを生成する

## 処理概要

レポートデータを生成する
レポートデータの構成は以下

* レポート
    * 対象年
    * 対象月
    * 精算レポート/月
        * 未精算データ件数
        * 未精算データリスト(※)
            * 未精算データ
                * メンバーID
                * メンバー名
                * 未精算金額
        * 未精算データ合計金額
    * 残高レポート/月
        * カテゴリーリスト(※)
            * カテゴリー
                * カテゴリーID
                * カテゴリー名
                * 残高
        * 合計残高

## APIパス

| パス         |
|:-----------|
| api/report |

## リクエストパラメータ

| パラメータ名         | 必須 | 属性     | 桁数 | 説明          |
|:---------------|:---|:-------|:---|:------------|
| groups_id      | ○  | String | 64 | 所属グループID    |
| group_password | ○  | String | 64 | 所属グループパスワード |
| yyyy           | ○  | Int    | 4  | 対象年         |
| mm             | ○  | Int    | 2  | 対象月         |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名 | 属性     | 説明                   |
|:-------|:-------|:---------------------|
| report | Object | 後述の「reportオブジェクト」を参照 |

#### reportオブジェクト

| パラメータ名            | 属性     | 説明                              |
|:------------------|:-------|:--------------------------------|
| target_year       | Int    | 対象年（yyyy）                       |
| target_month      | Int    | 対象月（mm）                         |
| settlement_report | Object | 後述の「settlement_reportオブジェクト」を参照 |
| balance_report    | Object | 後述の「balance_reportオブジェクト」を参照    |

#### settlement_reportオブジェクト

| パラメータ名                  | 属性          | 説明                                    |
|:------------------------|:------------|:--------------------------------------|
| un_settlement_count     | Int         | 未精算データ件数                              |
| un_settlement_data_list | List:Object | 後述の「un_settlement_data_listオブジェクト」を参照 |
| un_settlement_total     | Int         | 未精算データ合計金額                            |

#### un_settlement_data_listオブジェクト

| パラメータ名        | 属性     | 説明                          |
|:--------------|:-------|:----------------------------|
| un_settlement | Object | 後述の「un_settlementオブジェクト」を参照 |

#### un_settlementオブジェクト

| パラメータ名               | 属性     | 説明     |
|:---------------------|:-------|:-------|
| member_id            | Int    | メンバーID |
| member_name          | String | メンバー名  |
| un_settlement_amount | Int    | 未精算金額  |

#### balance_reportオブジェクト

| パラメータ名        | 属性          | 説明                          |
|:--------------|:------------|:----------------------------|
| category_list | List:Object | 後述の「category_listオブジェクト」を参照 |
| balance_total | Int         | 合計残高                        |

#### category_listオブジェクト

| パラメータ名   | 属性     | 説明                     |
|:---------|:-------|:-----------------------|
| category | Object | 後述の「categoryオブジェクト」を参照 |

#### categoryオブジェクト

| パラメータ名         | 属性     | 説明      |
|:---------------|:-------|:--------|
| category_id    | Int    | カテゴリーID |
| category_name  | String | カテゴリー名  |
| balance_amount | Int    | 残高      |

### 失敗時

[共通レスポンスパラメータ_エラー](../共通レスポンスパラメータ_エラー.md)
に従う
