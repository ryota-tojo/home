コメントを参照する

## 処理概要

コメントを参照する

## APIパス

| パス                |
|:------------------|
| api/comment/refer |

## リクエストパラメータ

| パラメータ名    | 必須 | 属性     | 桁数 | 説明       |
|:----------|:---|:-------|:---|:---------|
| groups_id |    | String | 64 | 所属グループID |
| yyyy      |    | Int    | -  | 対象年      |
| mm        |    | Int    | -  | 対象月      |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名       | 属性          | 説明                         |
|:-------------|:------------|:---------------------------|
| comment_list | List:Object | 後述の「comment_listオブジェクト」を参照 |

#### comment_listオブジェクト

| パラメータ名     | 属性     | 説明                 |
|:-----------|:-------|:-------------------|
| comment_id | Int    | コメントID             |
| groups_id  | String | 所属グループID           |
| yyyy       | Int    | 対象年                |
| mm         | Int    | 対象月                |
| content    | String | コメント内容             |
| fixed      | Int    | 確定フラグ（0:未確定, 1:確定） |

### 失敗時

[共通レスポンスパラメータ_エラー](../共通レスポンスパラメータ_エラー.md)
に従う
