# コメント登録API

## 目的

コメントを登録する

## 処理概要

コメントを登録する

## HTTPメソッド

| HTTPメソッド |
|:---------|
| POST     |

## APIパス

| パス               |
|:-----------------|
| api/comment/save |

## リクエストパラメータ

| パラメータ名    | 必須 | 属性     | 桁数    | 説明       |
|:----------|:---|:-------|:------|:---------|
| groups_id | ○  | String | 64    | 所属グループID |
| yyyy      | ○  | Int    | -     | 対象年      |
| mm        | ○  | Int    | -     | 対象月      |
| content   | ○  | String | 65535 | コメント内容   |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名  | 属性     | 説明                    |
|:--------|:-------|:----------------------|
| comment | Object | 後述の「commentオブジェクト」を参照 |

#### commentオブジェクト

| パラメータ名     | 属性     | 説明                 |
|:-----------|:-------|:-------------------|
| comment_id | Int    | コメントID             |
| groups_id  | String | 所属グループID           |
| yyyy       | Int    | 対象年                |
| mm         | Int    | 対象月                |
| content    | String | コメント内容             |
| fixed      | Int    | 確定フラグ（0:未確定, 1:確定） |

### 失敗時

[共通レスポンスパラメータ_エラー](../共通レスポンスパラメータ_エラー.md)
に従う
