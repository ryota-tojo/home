# ユーザー設定更新API

## 目的

ユーザー設定の更新を行う。

## 処理概要

ユーザー設定の更新を行う。

## HTTPメソッド

| HTTPメソッド |
|:---------|
| POST     |

## APIパス

| パス                      |
|:------------------------|
| api/user/update/setting |

## リクエストパラメータ

| パラメータ名        | 必須 | 属性     | 桁数  | 説明       |
|:--------------|:---|:-------|:----|:---------|
| user_id       | ○  | Int    | -   | ユーザーID   |
| setting_key   | ○  | String | 512 | ユーザー設定キー |
| setting_value | ○  | String | 256 | ユーザー設定値  |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名      | 属性  | 説明  |
|:------------|:----|:----|
| update_rows | Int | 更新行 |

### 失敗時

[共通レスポンスパラメータ_エラー](../共通レスポンスパラメータ_エラー.md)
に従う
