# ログイン判定API

## 目的

ユーザーのログイン判定を行う。

## 処理概要

ユーザー名、パスワードを元にログイン判定を行う。
ログインエラーとなる判定は以下。

* ユーザー名、パスワードの組み合わせが存在しない場合
* ユーザーが削除済み場合
* ユーザーが承認されていない場合

## APIパス

| パス        |
|:----------|
| api/login |

## リクエストパラメータ

| パラメータ名    | 必須 | 属性     | 桁数 | 説明        |
|:----------|:---|:-------|:---|:----------|
| user_name | ○  | String | 64 | ユーザー名     |
| password  | ○  | String | 64 | ユーザーパスワード |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性      | 説明                  |
|:--------|:--------|:--------------------|
| status  | String  | レスポンスステータス(success) |
| message | String  | レスポンスメッセージ          |
| login   | Boolean | ログイン判定              |

### 失敗時

[共通レスポンスパラメータ_エラー](../共通レスポンスパラメータ_エラー.md)
に従う
