# ユーザー削除API

## 目的

ユーザー情報の削除を行う。

## 処理概要

ユーザー情報の削除を行う。
削除対象のユーザーがリーダーの場合は削除失敗にする。

## APIパス

| パス              |
|:----------------|
| api/user/delete |

## リクエストパラメータ

| パラメータ名  | 必須 | 属性  | 桁数 | 説明     |
|:--------|:---|:----|:---|:-------|
| user_id | ○  | Int | -  | ユーザーID |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名      | 属性  | 説明  |
|:------------|:----|:----|
| update_rows | Int | 更新行 |

### 失敗時

[共通レスポンスパラメータ_エラー](../共通レスポンスパラメータ_エラー.md)
に従う
