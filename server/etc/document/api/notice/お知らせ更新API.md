# お知らせ更新API

## 目的

お知らせを更新する

## 処理概要

お知らせを更新する

## HTTPメソッド

| HTTPメソッド |
|:---------|
| POST     |

## APIパス

| パス                |
|:------------------|
| api/notice/update |

## リクエストパラメータ

| パラメータ名    | 必須 | 属性     | 桁数    | 説明     |
|:----------|:---|:-------|:------|:-------|
| notice_id | ○  | Int    | -     | お知らせID |
| title     | ○  | String | 1024  | タイトル   |
| content   | ○  | String | 65535 | 内容     |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名      | 属性  | 説明  |
|:------------|:----|:----|
| update_rows | Int | 更新行 |

### 失敗時

[共通レスポンスパラメータ_エラー](../共通レスポンスパラメータ_エラー.md)
に従う
