# お知らせ参照API

## 目的

お知らせを参照する

## 処理概要

お知らせを参照する

## APIパス

| パス               |
|:-----------------|
| api/notice/refer |

## リクエストパラメータ

| パラメータ名    | 必須 | 属性  | 桁数 | 説明     |
|:----------|:---|:----|:---|:-------|
| notice_id |    | Int | -  | お知らせID |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名      | 属性          | 説明                        |
|:------------|:------------|:--------------------------|
| notice_list | List:Object | 後述の「notice_listオブジェクト」を参照 |

#### notice_listオブジェクト

| パラメータ名          | 属性     | 説明                        |
|:----------------|:-------|:--------------------------|
| notice_id       | Int    | お知らせID                    |
| title           | String | タイトル                      |
| content         | String | 内容                        |
| create_datetime | String | 作成日時（YYYY-MM-DD hh:mm:ss） |
| update_datetime | String | 更新日時（YYYY-MM-DD hh:mm:ss） |

### 失敗時

[共通レスポンスパラメータ_エラー](../共通レスポンスパラメータ_エラー.md)
に従う
