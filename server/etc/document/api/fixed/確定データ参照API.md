# 確定データ参照API

## 目的

確定データを参照する

## 処理概要

対象年のすべての月に対し、確定データの状態を参照する

## HTTPメソッド

| HTTPメソッド |
|:---------|
| GET      |

## APIパス

| パス               |
|:-----------------|
| api/fixed/refers |

## リクエストパラメータ

| パラメータ名    | 必須 | 属性     | 桁数 | 説明        |
|:----------|:---|:-------|:---|:----------|
| groups_id | ○  | String | 64 | 所属グループID  |
| yyyy      | ○  | Int    |    | 対象年（YYYY） |
| mm        |    | Int    | -  | 対象月（MM）   |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名       | 属性     | 説明                         |
|:-------------|:-------|:---------------------------|
| fixed_result | Object | 後述の「fixed_resultオブジェクト」を参照 |

#### fixed_resultオブジェクト

| パラメータ名 | 属性  | 説明                       |
|:-------|:----|:-------------------------|
| 1月     | Int | 1月のデータ確定状況（0:未確定, 1:確定）  |
| 2月     | Int | 2月のデータ確定状況（0:未確定, 1:確定）  |
| 3月     | Int | 3月のデータ確定状況（0:未確定, 1:確定）  |
| 4月     | Int | 4月のデータ確定状況（0:未確定, 1:確定）  |
| 5月     | Int | 5月のデータ確定状況（0:未確定, 1:確定）  |
| 6月     | Int | 6月のデータ確定状況（0:未確定, 1:確定）  |
| 7月     | Int | 7月のデータ確定状況（0:未確定, 1:確定）  |
| 8月     | Int | 8月のデータ確定状況（0:未確定, 1:確定）  |
| 9月     | Int | 9月のデータ確定状況（0:未確定, 1:確定）  |
| 10月    | Int | 10月のデータ確定状況（0:未確定, 1:確定） |
| 11月    | Int | 11月のデータ確定状況（0:未確定, 1:確定） |
| 12月    | Int | 12月のデータ確定状況（0:未確定, 1:確定） |

### 失敗時

[共通レスポンスパラメータ_エラー](../共通レスポンスパラメータ_エラー.md)
に従う
