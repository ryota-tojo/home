# データ確定API

## 目的

データを確定する

## 処理概要

以下のデータに対し、確定フラグを「1」に設定する

* 予算
* 購入データ
* コメント

## HTTPメソッド

| HTTPメソッド |
|:---------|
| POST     |

## APIパス

| パス              |
|:----------------|
| api/fixed/fixed |

## リクエストパラメータ

| パラメータ名    | 必須 | 属性     | 桁数 | 説明        |
|:----------|:---|:-------|:---|:----------|
| groups_id | ○  | String | 64 | 所属グループID  |
| yyyy      | ○  | Int    |    | 対象年（YYYY） |
| mm        | ○  | Int    | -  | 対象月（MM）   |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名     | 属性     | 説明                       |
|:-----------|:-------|:-------------------------|
| fixed_rows | Object | 後述の「fixed_rowsオブジェクト」を参照 |

#### fixed_rowsオブジェクト

| パラメータ名   | 属性  | 説明        |
|:---------|:----|:----------|
| budgets  | Int | 予算 更新行    |
| shopping | Int | 購入データ 更新行 |
| comment  | Int | コメント 更新行  |

### 失敗時

[共通レスポンスパラメータ_エラー](../共通レスポンスパラメータ_エラー.md)
に従う
