# 前年対比API

## 目的

予算、購入データを元に予実対比データを生成する

## 処理概要

指定範囲の月のデータを集計し前年対比データを生成する
前年対比データは以下の構成で生成する

* カテゴリーリスト
    * カテゴリー
        * 1月
            * 前年支出額
            * 今年支出額
            * 差額
            * 前年対比(%)
        * 2月
        * 3月
        * 4月
        * 5月
        * 6月
        * 7月
        * 8月
        * 9月
        * 10月
        * 11月
        * 12月
        * 平均
        * 合計
* 総計リスト
    * 1月
    * 2月
    * 3月
    * 4月
    * 5月
    * 6月
    * 7月
    * 8月
    * 9月
    * 10月
    * 11月
    * 12月
    * 平均
    * 合計

※平均は、確定月のデータの合計と確定月の数で算出する

## リクエストパラメータ

| パラメータ名    | 必須 | 属性     | 桁数 | 説明        |
|:----------|:---|:-------|:---|:----------|
| groups_id | ○  | String | 64 | 所属グループID  |
| yyyy      | ○  | Int    | -  | 対象年（YYYY） |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名        | 属性          | 説明                          |
|:--------------|:------------|:----------------------------|
| category_list | List:Object | 後述の「category_listオブジェクト」を参照 |
| total         | Object      | 後述の「totalオブジェクト」を参照         |

#### category_listオブジェクト

| パラメータ名     | 属性     | 説明                       |
|:-----------|:-------|:-------------------------|
| month_data | Object | 後述の「month_dataオブジェクト」を参照 |

#### month_dataオブジェクト

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| 1       | Object | 後述の「月別データオブジェクト」を参照 |
| 2...    | Object | 後述の「月別データオブジェクト」を参照 |
| 12      | Object | 後述の「月別データオブジェクト」を参照 |
| average | Object | 後述の「月別データオブジェクト」を参照 |
| total   | Object | 後述の「月別データオブジェクト」を参照 |

#### 月別データオブジェクト

| パラメータ名             | 属性     | 説明     |
|:-------------------|:-------|:-------|
| pre_expense_amount | Int    | 前年支出額  |
| expense_amount     | String | 今年支出額  |
| difference         | Int    | 差額     |
| yoy                | Int    | 使用率(%) |

#### totalオブジェクト

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| 1       | Object | 後述の「総計データオブジェクト」を参照 |
| 2...    | Object | 後述の「総計データオブジェクト」を参照 |
| 12      | Object | 後述の「総計データオブジェクト」を参照 |
| average | Object | 後述の「総計データオブジェクト」を参照 |
| total   | Object | 後述の「総計データオブジェクト」を参照 |

#### 総計データオブジェクト

| パラメータ名                   | 属性     | 説明     |
|:-------------------------|:-------|:-------|
| total_pre_expense_amount | Int    | 前年支出額  |
| total_expense_amount     | String | 今年支出額  |
| total_difference         | Int    | 差額     |
| total_yoy                | Int    | 使用率(%) |
