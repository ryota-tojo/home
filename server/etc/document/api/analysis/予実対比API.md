# 予実対比API

## 目的

予算、購入データを元に予実対比データを生成する

## 処理概要

月のデータを集計し予実対比データを生成する
予実対比データは以下の構成で生成する

* カテゴリーリスト
    * カテゴリーID
    * カテゴリー名
    * 月別データ
        * 1月
            * 使用金額 - 支出
            * 使用金額 - 収入＋予算
            * 平均
            * 使用率
            * 残金
        * 2月...
            * 使用金額 - 支出
            * 使用金額 - 収入＋予算
            * 平均
            * 使用率
            * 残金
    * 年間データ
        * 年間
            * 使用金額 - 支出
            * 使用金額 - 収入＋予算
            * 平均
            * 使用率
            * 残金
* 総計
    * 合計データ
        * 合計
            * 合計使用金額 - 支出
            * 合計使用金額 - 収入＋予算
            * 合計平均
            * 合計使用率
            * 合計残金

※平均は、確定月のデータの合計と確定月の数で算出する

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名        | 属性          | 説明                          |
|:--------------|:------------|:----------------------------|
| category_list | List:Object | 後述の「category_listオブジェクト」を参照 |
| total         | List:Object | 後述の「totalオブジェクト」を参照         |

#### category_listオブジェクト

| パラメータ名        | 属性          | 説明                       |
|:--------------|:------------|:-------------------------|
| category_id   | Int         | カテゴリーID                  |
| category_name | String      | カテゴリー名                   |
| month_data    | List:Object | 後述の「month_dataオブジェクト」を参照 |
| year_data     | List:Object | 後述の「year_dataオブジェクト」を参照  |

#### month_dataオブジェクト

| パラメータ名 | 属性     | 説明                  |
|:-------|:-------|:--------------------|
| 1      | Object | 後述の「月別データオブジェクト」を参照 |
| 2...   | Object | 後述の「月別データオブジェクト」を参照 |
| 12     | Object | 後述の「月別データオブジェクト」を参照 |

#### 月別データオブジェクト

| average                   | Int | 平均    |

| パラメータ名 | 属性     | 説明                  |

| year   | Object | 後述の「年間データオブジェクト」を参照 |
