# 予算更新API

## 目的

予算を更新する

## 処理概要

予算を更新する

## APIパス

| パス                 |
|:-------------------|
| api/budgets/update |

## リクエストパラメータ

| パラメータ名      | 必須 | 属性     | 桁数 | 説明       |
|:------------|:---|:-------|:---|:---------|
| groups_id   | ○  | String | 64 | 所属グループID |
| yyyy        |    | Int    | -  | 対象年      |
| mm          |    | Int    | -  | 対象月      |
| category_id |    | Int    | -  | カテゴリーID  |
| amount      |    | Int    | -  | 金額       |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名      | 属性  | 説明  |
|:------------|:----|:----|
| update_rows | Int | 更新行 |

### 失敗時

[共通レスポンスパラメータ_エラー](../共通レスポンスパラメータ_エラー.md)
に従う
