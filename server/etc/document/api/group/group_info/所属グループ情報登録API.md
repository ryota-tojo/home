# 所属グループ情報登録API

## 目的

所属グループ情報を登録する

## 処理概要

所属グループ情報を登録する

## HTTPメソッド

| HTTPメソッド |
|:---------|
| POST     |

## APIパス

| パス                  |
|:--------------------|
| api/group/info/save |

## リクエストパラメータ

| パラメータ名    | 必須 | 属性     | 桁数 | 説明       |
|:----------|:---|:-------|:---|:---------|
| groups_id | ○  | String | 64 | 所属グループID |
| user_id   | ○  | Int    | -  | ユーザーID   |
| leader    | ○  | Int    | -  | リーダーフラグ  |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名     | 属性     | 説明                       |
|:-----------|:-------|:-------------------------|
| group_info | Object | 後述の「group_infoオブジェクト」を参照 |

#### group_infoオブジェクト

| パラメータ名      | 属性     | 説明                      |
|:------------|:-------|:------------------------|
| groups_id   | String | 所属グループID                |
| user_id     | Int    | ユーザーID                  |
| leader      | Int    | リーダーフラグ（0:メンバー, 1:リーダー） |
| approval    | Int    | 承認フラグ（0:未承認, 1:承認済）     |
| create_date | String | 作成日（YYYY-MM-DD）         |
| update_date | String | 更新日（YYYY-MM-DD）         |

### 失敗時

[共通レスポンスパラメータ_エラー](../../共通レスポンスパラメータ_エラー.md)
に従う
