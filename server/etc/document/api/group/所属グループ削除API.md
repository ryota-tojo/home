# 所属グループ削除API

## 目的

所属グループの情報を削除する

## 処理概要

所属グループに紐づく以下の情報を削除する

* 所属グループ一覧
* 所属グループ設定
* 所属グループ情報
* カテゴリー
* メンバー
* 購入データ入力テンプレート
* 購入データ検索テンプレート
* 購入データ登録テンプレート
* 予算
* 購入データ
* 確定データ
* コメント
* お付き合い帳

## HTTPメソッド

| HTTPメソッド |
|:---------|
| POST     |

## APIパス

| パス               |
|:-----------------|
| api/group/delete |

## リクエストパラメータ

| パラメータ名    | 必須 | 属性     | 桁数 | 説明       |
|:----------|:---|:-------|:---|:---------|
| groups_id | ○  | String | 64 | 所属グループID |

## レスポンスパラメータ

### 成功時

| パラメータ名      | 属性     | 説明                        |
|:------------|:-------|:--------------------------|
| status      | String | レスポンスステータス(success)       |
| message     | String | レスポンスメッセージ                |
| delete_rows | Object | 後述の「delete_rowsオブジェクト」を参照 |

#### delete_rowsオブジェクト

| パラメータ名                   | 属性  | 説明                |
|:-------------------------|:----|:------------------|
| group_list               | Int | 所属グループ一覧 削除行      |
| group_setting            | Int | 所属グループ設定 削除行      |
| group_info               | Int | 所属グループ情報 削除行      |
| category                 | Int | カテゴリー 削除行         |
| member                   | Int | メンバー 削除行          |
| shopping_input_Template  | Int | 購入データ入力テンプレート 削除行 |
| shopping_search_Template | Int | 購入データ検索テンプレート 削除行 |
| shopping_entry_Template  | Int | 購入データ登録テンプレート 削除行 |
| budgets                  | Int | 予算 削除行            |
| shopping                 | Int | 購入データ 削除行         |
| fixed                    | Int | 確定データ 削除行         |
| comment                  | Int | コメント 削除行          |
| communication            | Int | お付き合い帳 削除行        |

### 失敗時

[共通レスポンスパラメータ_エラー](../共通レスポンスパラメータ_エラー.md)
に従う
