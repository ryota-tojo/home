# 所属グループ一覧更新API

## 目的

所属グループ一覧の情報を更新する

## 処理概要

所属グループ一覧の情報を更新する

## HTTPメソッド

| HTTPメソッド |
|:---------|
| POST     |

## APIパス

| パス                    |
|:----------------------|
| api/group/update/list |

## リクエストパラメータ

| パラメータ名         | 必須 | 属性     | 桁数 | 説明          |
|:---------------|:---|:-------|:---|:------------|
| groups_id      | ○  | String | 64 | 所属グループID    |
| group_name     |    | String | 64 | 所属グループ名     |
| group_password |    | String | 64 | 所属グループパスワード |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名      | 属性  | 説明  |
|:------------|:----|:----|
| update_rows | Int | 更新行 |

### 失敗時

[共通レスポンスパラメータ_エラー](../共通レスポンスパラメータ_エラー.md)
に従う
