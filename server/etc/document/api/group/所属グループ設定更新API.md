# 所属グループ設定更新API

## 目的

所属グループ設定の情報を更新する

## 処理概要

所属グループ設定の情報を更新する

## APIパス

| パス                       |
|:-------------------------|
| api/group/update/setting |

## リクエストパラメータ

| パラメータ名       | 必須 | 属性     | 桁数  | 説明         |
|:-------------|:---|:-------|:----|:-----------|
| groups_id    | ○  | String | 64  | 所属グループID   |
| settingKey   |    | String | 512 | 所属グループ設定キー |
| settingValue |    | String | 256 | 所属グループ設定値  |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名      | 属性  | 説明  |
|:------------|:----|:----|
| update_rows | Int | 更新行 |

### 失敗時

[共通レスポンスパラメータ_エラー](../共通レスポンスパラメータ_エラー.md)
に従う
