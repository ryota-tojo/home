# 購入データ重複チェックAPI

## 目的

購入データの重複をチェックする

## 処理概要

条件に一致する購入データが1件より多く存在する場合に「1」を返す

## APIパス

| パス                       |
|:-------------------------|
| api/shopping/duplication |

## リクエストパラメータ

| パラメータ名        | 必須 | 属性     | 桁数   | 説明                  |
|:--------------|:---|:-------|:-----|:--------------------|
| groups_id     |    | String | 64   | 所属グループID            |
| user_id       |    | Int    | -    | ユーザーID              |
| shopping_date |    | String | 10   | 購入日（YYYY-MM-DD）     |
| member_id     |    | Int    | -    | メンバーID              |
| category_id   |    | Int    | -    | カテゴリーID             |
| type          |    | Int    | -    | 種別                  |
| payment       |    | Int    | -    | 支払い方法               |
| settlement    |    | Int    | -    | 精算フラグ（0:未精算, 1:精算済） |
| amount        |    | Int    | -    | 金額                  |
| remarks       |    | String | 1024 | 備考                  |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名      | 属性  | 説明                     |
|:------------|:----|:-----------------------|
| duplication | Int | 重複フラグ（0:重複しない, 1:重複する） |

### 失敗時

[共通レスポンスパラメータ_エラー](../共通レスポンスパラメータ_エラー.md)
に従う
