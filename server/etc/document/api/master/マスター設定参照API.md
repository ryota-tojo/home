# マスター設定参照API

## 目的

マスター設定を参照する

## 処理概要

マスター設定を参照する

## HTTPメソッド

| HTTPメソッド |
|:---------|
| GET      |

## APIパス

| パス                       |
|:-------------------------|
| api/master/setting/refer |

## リクエストパラメータ

| パラメータ名 | 必須 | 属性     | 桁数  | 説明   |
|:-------|:---|:-------|:----|:-----|
| key    |    | String | 512 | 設定キー |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名       | 属性          | 説明                         |
|:-------------|:------------|:---------------------------|
| setting_list | List:Object | 後述の「setting_listオブジェクト」を参照 |

#### setting_listオブジェクト

| パラメータ名  | 属性     | 説明    |
|:--------|:-------|:------|
| key     | String | 設定キー  |
| value   | String | 設定値   |
| remarks | String | 設定の備考 |

### 失敗時

[共通レスポンスパラメータ_エラー](../共通レスポンスパラメータ_エラー.md)
に従う
