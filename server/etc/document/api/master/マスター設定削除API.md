# マスター設定削除API

## 目的

マスター設定を削除する

## 処理概要

マスター設定を削除する

## APIパス

| パス                        |
|:--------------------------|
| api/master/setting/delete |

## リクエストパラメータ

| パラメータ名 | 必須 | 属性     | 桁数  | 説明   |
|:-------|:---|:-------|:----|:-----|
| key    | ○  | String | 512 | 設定キー |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名      | 属性  | 説明  |
|:------------|:----|:----|
| delete_rows | Int | 削除行 |

### 失敗時

[共通レスポンスパラメータ_エラー](../共通レスポンスパラメータ_エラー.md)
に従う
