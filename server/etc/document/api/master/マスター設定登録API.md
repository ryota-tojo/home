# マスター設定登録API

## 目的

マスター設定を登録する

## 処理概要

マスター設定を登録する

## APIパス

| パス                      |
|:------------------------|
| api/master/setting/save |

## リクエストパラメータ

| パラメータ名  | 必須 | 属性     | 桁数  | 説明    |
|:--------|:---|:-------|:----|:------|
| key     | ○  | String | 512 | 設定キー  |
| value   | ○  | String | 512 | 設定値   |
| remarks | ○  | String | 512 | 設定の備考 |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名  | 属性     | 説明                    |
|:--------|:-------|:----------------------|
| setting | Object | 後述の「settingオブジェクト」を参照 |

#### setting_listオブジェクト

| パラメータ名  | 属性     | 説明    |
|:--------|:-------|:------|
| key     | String | 設定キー  |
| value   | String | 設定値   |
| remarks | String | 設定の備考 |

### 失敗時

[共通レスポンスパラメータ_エラー](../共通レスポンスパラメータ_エラー.md)
に従う
