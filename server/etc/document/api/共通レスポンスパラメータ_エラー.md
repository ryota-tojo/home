# レスポンスパラメータ_エラー

## 処理概要

* エラー時のレスポンスパラメータをここに定義する
* エラー時は、共通のパラメータ構成でレスポンスを返す

## レスポンスパラメータ

| パラメータ名  | 属性     | 説明                   |
|:--------|:-------|:---------------------|
| status  | String | レスポンスステータス(error)    |
| message | String | レスポンスメッセージ           |
| errors  | Object | 後述の「errorsオブジェクト」を参照 |

#### errorsオブジェクト

| パラメータ名    | 属性     | 説明            |
|:----------|:-------|:--------------|
| parameter | String | エラーを起こしたパラメータ |
| message   | String | エラーメッセージ      |
