# カテゴリー論理削除API

## 目的

カテゴリーに削除フラグを立てる

## 処理概要

カテゴリーに削除フラグを立てる

## HTTPメソッド

| HTTPメソッド |
|:---------|
| POST     |

## APIパス

| パス                   |
|:---------------------|
| api/category/disable |

## リクエストパラメータ

| パラメータ名      | 必須 | 属性  | 桁数 | 説明      |
|:------------|:---|:----|:---|:--------|
| category_id |    | Int | -  | カテゴリーID |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名       | 属性  | 説明    |
|:-------------|:----|:------|
| disable_rows | Int | 論理削除行 |

### 失敗時

[共通レスポンスパラメータ_エラー](../共通レスポンスパラメータ_エラー.md)
に従う
