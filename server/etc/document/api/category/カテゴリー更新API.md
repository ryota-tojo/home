# カテゴリー更新API

## 目的

カテゴリーを更新する

## 処理概要

カテゴリーを更新する

## HTTPメソッド

| HTTPメソッド |
|:---------|
| POST     |

## APIパス

| パス                  |
|:--------------------|
| api/category/update |

## リクエストパラメータ

| パラメータ名        | 必須 | 属性     | 桁数 | 説明      |
|:--------------|:---|:-------|:---|:--------|
| category_id   | ○  | Int    | -  | カテゴリーID |
| category_no   |    | Int    | -  | カテゴリーNo |
| category_name |    | String | 64 | カテゴリー名  |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名      | 属性  | 説明  |
|:------------|:----|:----|
| update_rows | Int | 更新行 |

### 失敗時

[共通レスポンスパラメータ_エラー](../共通レスポンスパラメータ_エラー.md)
に従う
