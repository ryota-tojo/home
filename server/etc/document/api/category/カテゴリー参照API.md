# カテゴリー参照API

## 目的

カテゴリーを参照する

## 処理概要

カテゴリーを参照する

## HTTPメソッド

| HTTPメソッド |
|:---------|
| GET      |

## APIパス

| パス                 |
|:-------------------|
| api/category/refer |

## リクエストパラメータ

| パラメータ名      | 必須 | 属性     | 桁数 | 説明       |
|:------------|:---|:-------|:---|:---------|
| category_id |    | Int    | -  | カテゴリーID  |
| groups_id   |    | String | 64 | 所属グループID |
| category_no |    | Int    | -  | カテゴリーNo  |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名        | 属性          | 説明                          |
|:--------------|:------------|:----------------------------|
| category_list | List:Object | 後述の「category_listオブジェクト」を参照 |

#### category_listオブジェクト

| パラメータ名        | 属性     | 説明       |
|:--------------|:-------|:---------|
| category_id   | Int    | カテゴリーID  |
| groups_id     | String | 所属グループID |
| category_no   | Int    | カテゴリーNo  |
| category_name | String | カテゴリー名   |

### 失敗時

[共通レスポンスパラメータ_エラー](../共通レスポンスパラメータ_エラー.md)
に従う
