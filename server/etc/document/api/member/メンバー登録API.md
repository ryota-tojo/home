# メンバー登録API

## 目的

メンバーを登録する

## 処理概要

メンバーを登録する

## HTTPメソッド

| HTTPメソッド |
|:---------|
| POST     |

## APIパス

| パス              |
|:----------------|
| api/member/save |

## リクエストパラメータ

| パラメータ名      | 必須 | 属性     | 桁数 | 説明       |
|:------------|:---|:-------|:---|:---------|
| groups_id   | ○  | String | 64 | 所属グループID |
| member_no   | ○  | Int    | -  | メンバーNo   |
| member_name | ○  | String | 64 | メンバー名    |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名      | 属性     | 説明       |
|:------------|:-------|:---------|
| member_id   | Int    | メンバーID   |
| groups_id   | String | 所属グループID |
| member_no   | Int    | メンバーNo   |
| member_name | String | メンバー名    |

### 失敗時

[共通レスポンスパラメータ_エラー](../共通レスポンスパラメータ_エラー.md)
に従う
