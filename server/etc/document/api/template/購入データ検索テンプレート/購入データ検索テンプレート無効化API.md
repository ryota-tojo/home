# 購入データ検索テンプレート無効化API

## 目的

購入データ検索テンプレートを未使用状態に変更する

## 処理概要

購入データ検索テンプレートの使用フラグを「0」に更新する

## HTTPメソッド

| HTTPメソッド |
|:---------|
| POST     |

## APIパス

| パス                         |
|:---------------------------|
| api/template/input/unusage |

## リクエストパラメータ

| パラメータ名      | 必須 | 属性     | 桁数 | 説明       |
|:------------|:---|:-------|:---|:---------|
| groups_id   | ○  | String | 64 | 所属グループID |
| template_id | ○  | String | 64 | テンプレートID |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名      | 属性  | 説明  |
|:------------|:----|:----|
| update_rows | Int | 更新行 |

### 失敗時

[共通レスポンスパラメータ_エラー](../../共通レスポンスパラメータ_エラー.md)
に従う
