# 購入データ検索テンプレート参照API

## 目的

購入データ検索テンプレートを参照する

## 処理概要

購入データ検索テンプレートを参照する

## HTTPメソッド

| HTTPメソッド |
|:---------|
| GET      |

## APIパス

| パス                       |
|:-------------------------|
| api/template/input/refer |

## リクエストパラメータ

| パラメータ名      | 必須 | 属性     | 桁数 | 説明       |
|:------------|:---|:-------|:---|:---------|
| groups_id   |    | String | 64 | 所属グループID |
| template_id |    | String | 64 | テンプレートID |

## レスポンスパラメータ

### 成功時

| パラメータ名  | 属性     | 説明                  |
|:--------|:-------|:--------------------|
| status  | String | レスポンスステータス(success) |
| message | String | レスポンスメッセージ          |
| data    | Object | 後述の「dataオブジェクト」を参照  |

#### dataオブジェクト

| パラメータ名        | 属性          | 説明                          |
|:--------------|:------------|:----------------------------|
| template_list | List:Object | 後述の「template_listオブジェクト」を参照 |

#### template_listオブジェクト

| パラメータ名        | 属性     | 説明                  |
|:--------------|:-------|:--------------------|
| id            | Int    | ID                  |
| groups_id     | String | 所属グループID            |
| template_id   | String | テンプレートID            |
| template_name | String | テンプレート名             |
| member_id     | Int    | メンバーID              |
| category_id   | Int    | カテゴリーID             |
| type          | Int    | 種別                  |
| payment       | Int    | 支払い方法               |
| settlement    | Int    | 精算フラグ（0:未精算, 1:精算済） |
| amount        | Int    | 金額                  |
| remarks       | String | 備考                  |
| use           | Int    | 使用フラグ（0:未使用, 1:使用）  |
| deleted       | Int    | 削除フラグ（0:未削除, 1:削除済） |

### 失敗時

[共通レスポンスパラメータ_エラー](../../共通レスポンスパラメータ_エラー.md)
に従う
